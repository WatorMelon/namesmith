04

常见问题

会被杀毒软件或 Windows 拦截吗？

安装包和数据都做了代码签名，签名可以证明文件没有在传输中被替换。但这张证书是自签的开发证书，没有购买商业信誉，所以陌生电脑上仍可能弹出 SmartScreen 提示，这是未建立信誉的新软件的正常现象。

如果希望完全不出现提示，需要换成受信任的付费代码签名证书；这一步不改变软件本身。

生成的名字能直接拿去注册吗？

不能。工具只负责把名字造得好念、好记、有结构，不查商标、不查域名、不查平台账号是否被占用。正式启用前，请自己在商标库、域名注册商和各平台检索一遍。

为什么中文名是楷体？

中文名走的是「名帖」的路子，用楷体排出来更像一枚写好的名字，而不是产品说明书。中文名本身也按词素取意，不是音译。

支持 macOS 或 Linux 吗？

暂时只有 Windows 10 / 11 的 x64 版本。界面基于 Electron，之后可以移植，但当前没有对应安装包。

软件会联网或上传我的数据吗？

不会。命名词库打包在程序内部，界面不发起任何对外请求。收藏只保存在本机用户目录，卸载时删除。
